# Futurons — MVP

Futurons est un site collaboratif pour partager des idées, des projets, des réalisations et des procédés positifs afin de construire ensemble un monde plus heureux.

## Site web

La page d'accueil est dans `index.html` et peut être publiée avec GitHub Pages.

## Activer GitHub Pages

Dans **Settings → Pages**, sélectionner **Deploy from a branch**, puis la branche **main** et le dossier **/(root)**, et enregistrer.

## État du projet

Page d'accueil initiale du MVP. Les fonctions de contribution seront développées ultérieurement.
